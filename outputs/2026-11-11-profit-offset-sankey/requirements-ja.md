# WOW2026 W47: Let's Build a Converging Sankey!

## はじめに

Tableau Data Apps を AI と一緒に触っていたとき、AI が利益をサンキーダイアグラムで見せてくれました。赤字の明細も帯になって流れ、黒字と打ち消し合って純額に収束していく形でした。サンキーは帯の幅で量を表すので、負の値は扱えないものだと思っていました。この表現を、Tableau のワークブックでも再現してみたくなりました。

今回は、負の値も扱えるサンキーダイアグラムを作ります。サンキーの基本の作り方は、Olivier Catherin の [Polygon Sankey](https://www.dataplusscience.com/SankeyPolygon.html) が参考になります。楽しんでください！

## 要件

- ダッシュボードサイズ: 800 x 1000
- Ship Mode と Region のフィルターを、すべての要素に適用する
  - Same Day と South を選ぶと純額がマイナスになる。この組み合わせでも描けることを確かめる
- データの 1 行（明細行。Order ID 単位ではない）ごとに、Profit が 0 以上なら Gains、負なら Loss とする。帯の幅は、どちらも金額の絶対値で測る
- カテゴリは、純額の小さい順に左から並べる
- 帯は、いちばん上と下で Net Profit の棒に収束する。Gains と Loss は打ち消し合い、小さいほうの帯は消え、大きいほうの帯は純額の幅だけ残る
  - ヒント: 普通のサンキーと違うのは、収束する端の幅だけです。帯ごとに、同じグループ（全体、またはカテゴリ）の反対側の符号の幅を差し引きます。たとえば Furniture は Gains $81,405、Loss $61,675 なので、Gains の帯だけが $19,730 分の幅で残ります。残った帯は Loss と Gains の境目に寄せます（下の収束では、各カテゴリの中の境目）
