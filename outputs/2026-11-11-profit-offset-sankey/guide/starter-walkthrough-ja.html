手順

手順 1：残る幅を計算する（Opposite Width・Net Width）

上端で各帯に残る幅を計算します。要件の例では、Furniture は Gains $81,405、Loss $61,675 です。Gains の帯だけが $19,730 分の幅で残り、Loss の帯は幅 0 になります。

ヒント

  • 残る幅 = 自分の幅 − 反対側の符号の幅。ただし 0 未満にはしない
  • 反対側の幅は表計算で取れる。同じグループの Loss + Gains の合計から、自分の幅を引く
  • 計算を 2 本に分けると、表計算の方向を別々に設定できる
答え：Opposite Width と Net Width

Opposite Width 表計算Net Width の中

// Width of the other Sign in the same group.
// 0 when the other Sign does not exist
// Gains + Loss in this group
WINDOW_SUM([Band Width])
// minus my own width
- [Band Width]
  • 同じグループにいる反対側の符号の幅
  • 「グループ」が何かは、表計算の方向で決まる。章 A では全体、章 C ではカテゴリ

Net Width Position 0 MIN/MAX の中

// What is left after Gains and Loss cancel out.
// The larger Sign keeps the difference
MAX(
    [Band Width] - [Opposite Width],
    0
)
  • 大きいほうの符号は差が残り、小さいほうは 0 になる
  • 「どちらが大きいか」の IF は要らない。純額がマイナスでも同じ式で描ける

手順 2：上端の左右端を計算する（Position 0 MIN/MAX）

残る幅が分かったので、上端のどこに置くかを決めます。

ヒント

  • 残った幅を Loss と Gains の境目に寄せる。そうすると、上端の帯が 1 本の Net の棒にまとまる
  • Loss の帯は右端（境目）を、Gains の帯は左端（境目）を動かさない。反対の端だけを縮める
  • 境目の位置は、下端の Position 1 MIN/MAX から取れる
答え：Position 0 MIN / MAX

Position 0 MIN Curve Polygon 0-1 の中、上端の左端

// The leftover width stays next to the
// boundary between Loss and Gains
IIF(
    ATTR([Sign]) = 'Loss',
    // Loss: keep the right part
    [Position 1 MAX] - [Net Width],
    // Gains: keep the left part
    [Position 1 MIN]
)
  • Loss は右端（境目）から残りの幅だけ左へ
  • Gains は左端（境目）のまま

Position 0 MAX Curve Polygon 0-1 の中、上端の右端

// Right edge = left edge plus what is left
[Position 0 MIN] + [Net Width]
  • Net Width が 0 の帯は、左右端が一致して一点にすぼまる

確認：検算シートに 2 本足す

Check の Measure Values に Position 0 MIN と Position 0 MAX を足します。入れ子の計算（Band Width・Position 1 MAX・Opposite Width）は、すべて Sign だけにチェックします。

Loss の上端は 0.259 の一点です。Gains の上端は 0.259〜0.741 です。Loss が 0〜0.259 に、Gains が 0.741〜1 に出たら、Sign の並びが Loss → Gains になっているか確かめてください。
