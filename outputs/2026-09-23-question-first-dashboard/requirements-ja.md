# WOW2026 W{N}: Can You Build a Weekly Question-First Dashboard?（ドラフト v4）

## はじめに

AIエージェントやモバイル通知のおかげで、ダッシュボードを「開いて探す」機会はどんどん減っています。これからのBIは、「この問いの答えだけは全員が知っておこうね」というものを毎週スマホに届ける形に近づいていくはずです。そうなると大事なのは、チャートの種類より先に「どの問いに答えるのか」をはっきりさせることです。

今回は Superstore の1週間について、全員が共有すべき問いを並べ、それぞれに Yes / No と数字1つ、小さなチャートで答えるダッシュボードを作ります。週の数字はとてもぶれやすいので、「先週より良かったか」ではなく「最近の自分たちと比べて普段並みか」「去年の同じ時期と比べてどうか」を問います。

## 要件

- ダッシュボードサイズ: 420 x 1050（スマホで縦にスクロールする想定）
- データ: Sample - Superstore-2026.xlsx（WOW データリポジトリ）
- 週は日曜始まりとする
- 対象週を選ぶパラメータを作る。初期値はデータ内で最後の、7日すべてそろった週とする
- ヘッダーに、全6問の Yes / No を横一列に並べる（売上 Q1〜Q2・利益 Q3〜Q4・売上の中身 Q5〜Q6）
- 売上（Sales）と利益（Profit）を左右2列に並べ、次の2つの問いに答える
  - 今週は普段並み以上だったか？ 直前13週の平均 − 1標準偏差以上なら Yes。利益は赤字なら No
  - 去年の同じ時期並み以上だったか？ 前年の同じ13週（52週前にずらした13週）の平均 − 1標準偏差以上なら Yes
- 売上の中身として、注文数と注文単価（売上 ÷ 注文数）も「去年の同じ時期並み以上か？」で答える
- チャートはすべて、直近の週次の棒グラフに比較対象の帯（平均 ± 1標準偏差）を重ねる形にそろえる
- 去年の同じ時期と比べるチャートでは、各週の棒を帯より上・帯の中・帯より下で色分けし、13週のうちそれぞれ何週あったかを表示する
- 今週の棒は、他の週より濃く表示する
- ツールチップとフォーマットをできるだけ再現すること
