# WOW2026 W{N}: Can You Build a Weekly Question-First Dashboard?（ドラフト v11）

## はじめに

AIエージェントやモバイル通知のおかげで、ダッシュボードを「開いて探す」機会はどんどん減っています。これからのBIは、「この問いの答えだけは全員が知っておこうね」というものを毎週スマホに届ける形に近づいていくはずです。そうなると大事なのは、チャートの種類より先に「どの問いに答えるのか」をはっきりさせることです。

今回は Superstore の1週間について、全員が共有すべき4つの問いに、Yes / No と数字1つ、小さなチャートで答えるダッシュボードを作ります。週の数字はとてもぶれやすい（数件の大口注文で1週間が大きく動く）ので、「先週より良かったか」ではなく「普段より良かったか」「去年の同じ時期より良かったか」を問い、その差がただのノイズなのか、見ておくべき動きなのかまで答えます。いくつか計算が組み合わさるので、中級向けのワークアウトです。楽しんでください！

## 要件

- ダッシュボードサイズ: 420 x 1000（スマホで縦にスクロールする想定）
- シート数: 8（チャート4、ヘッダーの答え一覧1、ヘッダーの対象週と件数1、KPI カード2）
- データ: Sample - Superstore-2026.xlsx（WOW データリポジトリ）
- データソース画面で Sales と Profit を Pivot し、Metric / Value の2列にする（1組の計算で両指標をまかなうため）
- 週は日曜始まりとする
- 対象週を選ぶパラメータを作る。選べるのは直近8週の週初め（日曜）だけで、2026-06-21〜2026-08-09。初期値は 2026-08-09 の週とする
- 売上（Sales）と利益（Profit）を左右2列に並べ、次の2つの問いに答える
  - 今週は普段より良かったか？ 直前13週と比べる。平均・標準偏差には今週を含めない
  - 去年の同じ時期より良かったか？ 前年の同じ13週と比べる。今週を含む直近13週を、52週前にずらした13週（52週＝364日なので曜日がそろう）
- 比較期間の平均以上なら Yes、未満なら No とする
- 比較期間の範囲を「平均 ± 1標準偏差」（標本標準偏差）とする
- ヘッダーに次を表示する
  - 対象週と、範囲の外に出た問いの件数
  - 4問の Yes / No を、行を問い・列を売上と利益にした 2 x 2 のタイルで並べる。タイルの色は今週の位置の4段階（範囲より上・平均以上・平均未満・範囲より下）で塗り分け、範囲の外には ▲ / ▼ を付ける
- 段ごとに、指標ごとの KPI カードを置く。今週の値、平均との差額（$）を表示し、範囲の外に出たときだけ上限・下限からの差を ▲ / ▼ 付きで添える。
- 1段目のチャート: 直前13週の棒に範囲の帯と平均線を重ねる（アナリティクスペインで足りる）。平均線は今週の手前で止める。今週の棒は少し離し、タイルと同じ4段階の色で塗る
- 2段目のチャート: 今年の直近13週と前年の同じ13週を折れ線で重ね、前年の平均線と範囲の帯を描く。今年の線を前面に出し、今週の点はタイルと同じ4段階の色の円で強調する
- 段のチャートの下に、線・平均線・帯の意味を右揃えの1行の凡例で示す
- チャートに値ラベルは付けない（今週の値は KPI カードにある）
- フォーマットをできるだけ再現すること
