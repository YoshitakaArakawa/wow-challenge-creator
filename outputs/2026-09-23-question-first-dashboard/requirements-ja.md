# WOW2026 W{N}: Can You Build a Weekly Question-First Dashboard?（ドラフト v10）

## はじめに

AIエージェントやモバイル通知のおかげで、ダッシュボードを「開いて探す」機会はどんどん減っています。これからのBIは、「この問いの答えだけは全員が知っておこうね」というものを毎週スマホに届ける形に近づいていくはずです。そうなると大事なのは、チャートの種類より先に「どの問いに答えるのか」をはっきりさせることです。

今回は Superstore の1週間について、全員が共有すべき4つの問いに、Yes / No と数字1つ、小さなチャートで答えるダッシュボードを作ります。週の数字はとてもぶれやすい（数件の大口注文で1週間が大きく動く）ので、「先週より良かったか」ではなく「普段より良かったか」「去年の同じ時期より良かったか」を問い、その差がただのノイズなのか、見ておくべき動きなのかまで答えます。いくつか計算が組み合わさるので、中級向けのワークアウトです。楽しんでください！

## 要件

- ダッシュボードサイズ: 420 x 950（スマホで縦にスクロールする想定）
- シート数: 6（チャート4、ヘッダーの答え一覧1、今週の一言1）
- データ: Sample - Superstore-2026.xlsx（WOW データリポジトリ）
- データソース画面で Sales と Profit を Pivot し、Metric / Value の2列にする（1組の計算で両指標をまかなうため）
- 週は日曜始まりとする
- 対象週を選ぶパラメータ（日付型）を作る。初期値は 2026-12-20 の週とする
- 売上（Sales）と利益（Profit）を左右2列に並べ、次の2つの問いに答える
  - 今週は普段より良かったか？ 直前13週と比べる。平均・標準偏差には今週を含めない
  - 去年の同じ時期より良かったか？ 前年の同じ13週（52週前にずらした13週）と比べる
- 比較期間の平均以上なら Yes、未満なら No とする
- 比較期間の範囲を「平均 ± 1標準偏差」（標本標準偏差）とする。範囲の外に出た問いは「注目」とし、上限・下限からの差を表示する。範囲内なら平均との差額（$）を表示する
- ヘッダーに、4問の Yes / No を売上・利益の2列で横に並べ、注目の問いには ⚠ などの記号を付け、注目の件数を表示する。答えは ✓ / ✕ の記号で足りる（文字の色分けは任意）
- ヘッダーに「今週の一言」を表示する。範囲の外に出た問いだけを文にし、残りは「ほかは範囲内です」とまとめる。注目がなければ「今週はすべて範囲内」と表示する
- 1行目のチャート: 直前13週の棒に範囲の帯と平均線を重ね（アナリティクスペインで足りる）、今週の棒は少し離して強調する
- 2行目のチャート: 今年の直近13週と前年の同じ13週を折れ線で重ね、前年の平均線と範囲の帯を描く。直近13週のうち前年の範囲より上・下だった週数も表示する
- 今週の値は、すべてのチャートで色と値ラベルで強調する
- ツールチップとフォーマットをできるだけ再現すること
