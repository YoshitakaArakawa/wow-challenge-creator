# WOW2026 W{N}: Can You Build a Question-First Dashboard?（ドラフト）

## はじめに

AIエージェントやモバイル通知のおかげで、ダッシュボードを「開いて探す」機会はどんどん減っています。これからのBIは、「この問いの答えだけは全員が知っておこうね」というものをスマホに届ける形に近づいていくはずです。そうなると大事なのは、チャートの種類より先に「どの問いに答えるのか」をはっきりさせることです。

今回は Superstore のビジネスについて、誰もが気にする5つの問いを縦に並べ、それぞれに Yes / No と数字1つ、そして小さなチャートで答えるダッシュボードを作ってみましょう。前月比・前年同月比・トレンドで答えが食い違うこともあります。その食い違いを一目で読めるようにするのが今回のポイントです。

## 要件

- ダッシュボードサイズ: 400 x 1400（スマホで縦にスクロールする想定）
- シート数: 5（問いごとに1シート）
- データ内の最新月を「今月」として扱う
- 各ブロックに、問い・答え（Yes / No）・キーとなる数字・ミニチャートを表示する
- 答えは Yes と No で色分けする
- 以下の5つの問いに答える:
  - Q1. 前月より売れているか？ 今月の Sales と前月比を表示する。ミニチャートは直近13か月の棒グラフで、今月と前月を強調する
  - Q2. 前年同月より売れているか？ 今月の Sales と前年同月比を表示する。ミニチャートは今年と前年の月次 Sales を重ねた折れ線にする
  - Q3. トレンドは上向きか？ 直近12か月の Sales 合計の前年比を表示する。ミニチャートは月次 Sales と12か月移動平均を重ねる
  - Q4. 利益はついてきているか？ 今月の Profit Ratio と前年同月との差（ポイント）を表示する。ミニチャートは Profit Ratio の月次推移にする
  - Q5. 伸びは全体に広がっているか？ 前年同月比がプラスの Region 数を「3 / 4」の形で表示する。過半数なら Yes とする。ミニチャートは Region 別の前年同月比の横棒にする
- 問いの文章は各ブロックの一番上に、答えより目立たないサイズで置く
- ツールチップとフォーマットをできるだけ再現すること
