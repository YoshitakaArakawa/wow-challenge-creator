# WOW2026 W40: Can You Build a Weekly Check-In Dashboard?（ドラフト v15）

## はじめに

Dreamforce 2026 の Tableau キーノートは見ましたか？ 大きな発表がたくさんあって、楽しかったです。同時に、これからのダッシュボードの居場所について考えさせられました。アドホックな分析は AI に移りつつあり、私たちはその変化の真っただ中にいるように感じます。今のところ、ダッシュボードの役割は「適切な情報を、適切なタイミングで届けること」だと考えています。ダッシュボードによっては、それは「チーム全員が知っておくべき少数の問い」に答えることになります。

今回は、そういうダッシュボードを作ります。4つの Yes / No の答えに、それぞれ数字1つと小さなチャートを添えます。週の数字はぶれることがあるので、先週とだけ比べるのではなく、普段の範囲と照らし合わせて答えます。楽しんでください！

## 要件

- ダッシュボードサイズ: 420 x 1000（スマホで縦にスクロールする想定）
- 週を選ぶパラメータを作る。選択肢は 2026-06-21〜2026-08-09 の8つの週初め（日曜）で、初期値は 2026-08-09。以下、選んだ週を「今週」と呼ぶ
- 売上（Sales）と利益（Profit）のそれぞれで、2つの問いに答える
  - 今週は普段より良かったか？ 今週の直前13週と比べる
  - 去年の同じ時期より良かったか？ 今週で終わる13週を、52週前にずらした13週と比べる（52週＝364日なので曜日がそろう）
- それぞれの比較で
  - 比較期間の平均以上なら Yes、未満なら No と答える
  - 範囲は平均 ± 1標本標準偏差。境界上の値は範囲内とする
  - 今週の位置で色を4段階に分ける
    - 範囲より上
    - 範囲内で平均以上
    - 範囲内で平均未満
    - 範囲より下
  - 範囲の外には ▲ / ▼ を付ける
- 表示する要素
  - ヘッダー
    - 4つの答えをタイルで並べる
    - 指標ごとに今週の金額を出す
  - KPI カード（問いごと・指標ごと）
    - 平均との差額（$）と平均そのものを出す
    - 範囲の外なら、境界からの差も出す
  - 普段との比較のチャート
    - 直前13週と今週の週次の値を棒グラフにする
    - 比較期間の範囲と平均を重ねる。範囲と平均線は今週の棒にはかからないようにする
  - 去年との比較のチャート
    - 今年の13週と前年の13週の週次の値を折れ線グラフで重ねる
    - 前年の範囲と平均を描く
- フォーマットをできるだけ再現すること
