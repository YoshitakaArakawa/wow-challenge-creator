# WOW2026 W{N}: Can You Build a Weekly Question-First Dashboard?（ドラフト v2）

## はじめに

AIエージェントやモバイル通知のおかげで、ダッシュボードを「開いて探す」機会はどんどん減っています。これからのBIは、「この問いの答えだけは全員が知っておこうね」というものを毎週スマホに届ける形に近づいていくはずです。そうなると大事なのは、チャートの種類より先に「どの問いに答えるのか」をはっきりさせることです。

今回は Superstore の1週間について、全員が共有すべき問いを並べ、それぞれに Yes / No と数字1つ、小さなチャートで答えるダッシュボードを作ります。週の数字はとてもぶれやすいので、「先週より良かったか」ではなく「普段並みか」「前年同週と比べてどうか」「年間のペースに乗っているか」を問います。

## 要件

- ダッシュボードサイズ: 420 x 1100（スマホで縦にスクロールする想定）
- データ: Sample - Superstore-2026.xlsx（WOW データリポジトリ）
- 週は日曜始まりとする
- 対象週を選ぶパラメータを作る。初期値はデータ内で最後の、7日すべてそろった週とする
- 売上（Sales）と利益（Profit）を左右2列に並べ、同じ3つの問いに答える
  - 今週は普段並み以上だったか？ 直前13週の平均 − 1標準偏差以上なら Yes。利益は赤字なら No。直近14週の棒グラフに、普段の範囲を帯で示す
  - 前年の同じ週より良かったか？ 52週前の週と比べる。直近13週について、今年と前年の折れ線を重ねる
  - 年累計で前年のペースに乗っているか？ 1月1日から対象週の土曜までの累計を、前年の同期間と比べる。週ごとの累計の折れ線を今年と前年で重ねる
- 売上の答えは % で、利益の答えは差額（$）で表示する
- 最後に、平均割引率が直前13週の平均 + 1標準偏差以下かどうかを問う（値引きに頼りすぎていないか？）
- 各問いの答えは Yes と No で色分けし、7問中いくつ Yes かをヘッダーに表示する
- ツールチップとフォーマットをできるだけ再現すること
