# WOW2026 W{N}: Can You Build a Weekly Question-First Dashboard?（ドラフト v3）

## はじめに

AIエージェントやモバイル通知のおかげで、ダッシュボードを「開いて探す」機会はどんどん減っています。これからのBIは、「この問いの答えだけは全員が知っておこうね」というものを毎週スマホに届ける形に近づいていくはずです。そうなると大事なのは、チャートの種類より先に「どの問いに答えるのか」をはっきりさせることです。

今回は Superstore の1週間について、全員が共有すべき問いを並べ、それぞれに Yes / No と数字1つ、小さなチャートで答えるダッシュボードを作ります。週の数字はとてもぶれやすいので、「先週より良かったか」ではなく「普段並みか」「前年同週と比べてどうか」「直近13週で前年を上回っているか」を問います。

## 要件

- ダッシュボードサイズ: 420 x 1200（スマホで縦にスクロールする想定）
- データ: Sample - Superstore-2026.xlsx（WOW データリポジトリ）
- 週は日曜始まりとする
- 対象週を選ぶパラメータを作る。初期値はデータ内で最後の、7日すべてそろった週とする
- ヘッダーに、全8問の Yes / No を横一列に並べる（売上 Q1〜Q3・利益 Q4〜Q6・売上の中身 Q7〜Q8）
- 売上（Sales）と利益（Profit）を左右2列に並べ、同じ3つの問いに答える
  - 今週は普段並み以上だったか？ 直前13週の平均 − 1標準偏差以上なら Yes。利益は赤字なら No。直近14週の棒グラフに、普段の範囲を帯で示す
  - 前年の同じ週より良かったか？ 52週前の週と比べる。直近13週について、今年と前年の折れ線を重ねる
  - 直近13週で前年を上回っているか？ 対象週までの13週合計を、52週前からの同じ13週と比べる。13週ローリング合計の折れ線を、今年と前年で重ねる
- 売上の答えは % で、利益の答えは差額（$）で表示する
- 最後の行で売上の中身を問う。どちらも前年同週と比べる
  - 注文数は増えたか？
  - 注文単価（売上 ÷ 注文数）は上がったか？
- 各問いの答えは Yes と No で色分けする
- ツールチップとフォーマットをできるだけ再現すること
