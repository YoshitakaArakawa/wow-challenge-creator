## ドラフト設計

### 基準月
データ内の最新月を「今月」とする。Superstore は月末までデータが揃っているため、未完了月の扱いは不要。

### 5つの問い
| # | 問い | 答え（判定） | 数字 | ミニチャート |
|---|---|---|---|---|
| Q1 | 前月より売れているか？ | Yes / No | Sales と前月比 % | 直近13か月の棒。最新月と前月を強調 |
| Q2 | 前年同月より売れているか？ | Yes / No | Sales と前年同月比 % | 今年と前年の月次線を重ねる |
| Q3 | トレンドは上向きか？ | Yes / No | 直近12か月合計の前年比 % | 月次 Sales と12か月移動平均 |
| Q4 | 利益はついてきているか？ | Yes / No | Profit Ratio と前年同月差（pt） | Profit Ratio の月次線 |
| Q5 | 伸びは全体に広がっているか？ | Yes / No（過半数か） | 前年同月比プラスの Region 数（例: 3 / 4） | Region 別 YoY % の横棒 |

### 設計意図
- Q1〜Q3 はユーザーの例そのもの。短期ノイズ（MoM）→季節性を除いた比較（YoY）→ノイズを均したトレンド、と見る時間軸が伸びていく
- Q4・Q5 は「売上は伸びているが…」という落とし穴を拾う問い。Yes が並ぶ中に No が1つ混じる構図が最もメッセージ性が高い
- Q1 が No でも Q2・Q3 が Yes なら「季節要因なので心配不要」と読める。問いを並べる意味はこの読み合わせにある

### 技術的ポイント（WOWとしての学習価値）
- 最新月のアンカー（FIXED LOD で最大日付を取り、相対月を計算）
- 問いごとに異なる比較期間の計算（前月・前年同月・12か月ローリング）
- Yes / No 判定を文字列で返し、判定で色を切り替える
- 移動平均やRegion別集計など、問いによってチャートの型が変わる
- 縦長モバイルレイアウトでのコンテナ設計（問いのブロックを縦に積む）
