このプロトタイプについて

Sample Superstore（Orders 9,994行）の実データで計算しています。データ内の最新月を「今月」として、5つの問いに Yes / No・数字1つ・ミニチャートで答えます。マークにカーソルを合わせると値が出ます。

使ったのは期間が2014〜2017年の版です。Tableau Desktop に同梱されている最新版は、同じ行で年だけずらしていると推測しています（何年ずれているかは未確認）。そのため年のラベルだけ変わり、数値や Yes / No は同じになる見込みです。

読み取れること

月単位の問い（Q1・Q2・Q4・Q5）は No が並びます。一方、Q3 のトレンドは直近12か月で前年比 +20% の Yes です。「12月だけ見ると悪いが、年間では伸びている。ただし利益率は落ちている」という読み合わせが、問いを並べたときに初めて見えます。
