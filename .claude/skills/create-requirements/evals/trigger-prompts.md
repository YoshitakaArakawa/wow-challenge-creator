# トリガーテスト

## 起動すべき（should fire）

- 要件を書いて
- 問題文を作って
- プロトタイプを見せて
- どんな見た目になるかイメージを見たい
- ワークブックができたので要件を仕上げて
- 要件を確定して。画像で分かることは削ってほしい
- Intro を書き直したい

## 起動すべきでない（should not fire）

- WOWのアイデアを出して
- ワークブックを作って
- Cloudにパブリッシュして
- 告知のポストを書いて
- このTWBXを解析して
