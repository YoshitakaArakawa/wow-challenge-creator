# トリガーテスト

## 起動すべき（should fire）

- 完成したワークブックの作り方の解説を作って
- ビルドガイドを作って
- 参加者向けに解答のヒントをまとめたい
- どう作ったかを図解した HTML がほしい
- 表計算の設定をダイアログの絵で説明するページを作って

## 起動すべきでない（should not fire）

- 要件を確定して
- ワークブックを作って
- この TWBX を解析して
- Cloud にパブリッシュして
- 告知のポストを書いて
