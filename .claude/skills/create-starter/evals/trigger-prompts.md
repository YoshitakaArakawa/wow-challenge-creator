# トリガーテスト

## 起動すべき（should fire）

- スターターを作って
- 初心者向けに、普通のサンキーまで組んだワークブックを配りたい
- 完成版から Link 0-1 と Link 2-3 を抜いた版を作って
- 定番部分だけ渡すスターター・ワークブックを用意したい
- スターターを作り直して。渡すシートを 1 枚増やしたい

## 起動すべきでない（should not fire）

- ワークブックを作って
- このTWBXを解析して
- Cloudにパブリッシュして
- 参加者向けの手順書を作って
- 要件を確定して
